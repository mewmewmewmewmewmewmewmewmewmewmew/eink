About

Every pixel is snapped to one of four colours — black, red, yellow, white — the palette used by 4-colour e-ink panels. What you see in the viewfinder is exactly what gets saved.

Photo keeps full tonal detail through dithering. Cel flattens the image into anime-style colour areas with inked outlines. Vector pushes that further — big poster-flat shapes, sticker-like. Halftone uses clustered print dots. Sketch keeps only the outlines on white.

Diffuse / Atkinson spread the quantisation error into neighbouring pixels for photographic texture. Ordered uses a fixed 8×8 pattern (cleaner, more retro). Flat does no dithering. The ink palette row restricts which of the four colours may be used — handy for two-tone panels or a deliberately red-only look.

Save PNG writes the image at exact panel resolution. Save .bin writes packed 2 bits per pixel, MSB first, rows padded to whole bytes, with 0=black, 1=white, 2=yellow, 3=red — the byte layout most Waveshare-style 4-colour panels expect.
