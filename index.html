About

Every pixel is snapped to one of four colours — black, red, yellow, white — the palette used by 4-colour e-ink panels. What you see in the viewfinder is exactly what gets saved.

Photo keeps full tonal detail through dithering. Cel flattens the image into anime-style colour areas with inked outlines. Vector pushes that further — big poster-flat shapes. Halftone uses clustered print dots. Sketch keeps only the outlines on white. Thermal reads the palette as a brightness ramp instead of as colours, for a false-colour look. Riso prints each ink as a separate pass, deliberately out of register. Engrave and Hatch draw with line screens that thicken as the tone darkens, and Contour traces iso-brightness lines like a map, with a Line weight control so thin lines survive whatever the panel's own uploader does to them. Those five share one Detail slider, relabelled to suit each.

Diffuse / Atkinson spread the quantisation error into neighbouring pixels for photographic texture. Ordered uses a fixed 8×8 pattern. Flat does no dithering. The ink palette row restricts which of the four colours may be used.

Crop and rotate: drag to reposition, pinch to zoom, and use ↺ ↻ to rotate. Gestures work anywhere in the preview area, including the space beside a narrow portrait panel. This works on the live view, on a photo you have just taken, and on any photo you upload.

Text is drawn after the image is reduced to four colours, so captions stay sharp instead of dissolving into the dither. Pick any ink for the letters and the outline, set the outline thickness, then use the Photo / Text pill over the preview to choose what dragging and pinching move, so the caption can be placed against a full-size preview. Up to nine captions are supported — the numbered tabs switch between them, and each keeps its own text, font, size, inks and position. Fonts come from the device, including four Japanese faces, so the distinctive ones look their best on iOS.

Ink colours — the four colours everything is quantised to. If the panel software maps to the display's own measured inks rather than pure RGB, set these to match: dithering against a palette you already match cannot change your image, while dithering against one you do not match scatters every pixel's error across its neighbours.

Check a file — pick any image and this reports what it really contains: its type, its size, and every colour in it. A phone screenshot cannot answer that, because zooming interpolates and screenshots are re-tagged to the display's colour space, so a pure file still looks impure on screen.



      
Save to Photos goes through the system share sheet, which is the only route into the iOS photo album from a web page. Save project keeps the shot editable — the background, the crop and every caption come back when you reopen it from the folder button. Point it at a server under Saved projects → Settings and projects live there rather than in browser storage, which phones are free to evict; the device is used only as a fallback when the server cannot be reached. Download PNG writes the image at exact panel resolution. Exports are always in the panel's native landscape frame — a portrait composition is turned a quarter turn on the way out, in whichever direction you pick in the save sheet, since the panel's buffer is the same shape however you mount it. .bin is packed 2 bits per pixel, MSB first, rows padded to whole bytes, with 0=black, 1=white, 2=yellow, 3=red.
